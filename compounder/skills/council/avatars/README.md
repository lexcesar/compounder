# The Council — bundled avatars

Fifteen counselors, designed in pairs that disagree. `/compounder:council` reads them from here
unless the project has its own `avatars/` folder at the repository root — the project copy always
wins, so copy this folder there to personalize it (the "Owner's notes" sections are where real
stories go: what happened, what was decided, what was learned; one at a time).

| Avatar | Domain | Motto |
|---|---|---|
| [Sage](01-sage.md) | Long term, discernment | "What does this mean ten years from now?" |
| [Brave](02-brave.md) | Fear, hard conversations, risk | "Courage is acting with fear present" |
| [Wealthy](03-wealthy.md) | Money, wealth | "Never bet the essential to win the superfluous" |
| [Teacher](04-teacher.md) | Teaching, learning | "To teach is to learn twice" |
| [Entrepreneur](05-entrepreneur.md) | Building, delivering | "Finished beats perfect" |
| [Objective — KISS](06-objective-kiss.md) | Simplicity | "Simplify until it hurts; stop one step short" |
| [Go-Horse](07-go-horse.md) | Conscious speed | "Done fast, with a warning sign and an expiry date" |
| [Giver](08-giver.md) | Generosity, legacy | "What blooms without you is what you truly made" |
| [Diligent Worker](09-diligent-worker.md) | Discipline, consistency | "Show up every day; intensity is a guest, constancy lives here" |
| [Curious](10-curious.md) | Questions, nonconformity | "Why is it like this? Says who?" |
| [Young One](11-young.md) | Audacity, energy | "What if it works?" |
| [Child](12-child.md) | Joy, presence | "If none of this makes money, is it still worth it?" |
| [Wise Woman](13-wise-woman.md) | Relationships, intuition, care | "Hear what was left unsaid" |
| [King](14-king.md) | Decision, responsibility, succession | "The kingdom must live without the king" |
| [Philosopher](15-philosopher.md) | Premises, meaning, death | "Examine the question before answering" |

Tensions built in: Wealthy ⇄ Young One (margin × window), Go-Horse ⇄ Diligent Worker (speed ×
finish), Child ⇄ King (lightness × duty), Objective ⇄ Philosopher (cutting × examining), Brave ⇄
Sage (acting × waiting), Entrepreneur ⇄ Giver (capturing × distributing). Where two avatars disagree
about your decision, that is where the real decision lives. A unanimous council is a badly convened one.

Avatars illuminate; they do not decide, and they do not replace people.
