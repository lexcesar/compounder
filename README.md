# Starter Kit: teaching a model to work like a senior engineer

This repository is a **blank project template** whose real content is not code — it's method.
It was distilled by Claude Fable 5 so that smaller models (Opus, Sonnet, Haiku) can operate, inside a
project, with the discipline of a senior engineer: read before writing, verify before claiming,
decide with judgment, learn from every correction.

The premise: **at runtime, the only "training" available is context.** A smaller model with
concrete, checkable rules loaded at the right moment beats a larger model running on improvisation.
This kit is those rules.

## How to adopt

**Prerequisite:** [Claude Code](https://claude.com/claude-code) installed. The kit has no
dependencies — it's pure content.

**New project:** copy the whole kit into the project directory (or fork / "Use this template"
on GitHub) and fill in the `[ADJUST: ...]` blocks in `CLAUDE.md`. Create `src/`, `tests/`, `scripts/`
as your stack requires (the kit is language- and stack-agnostic: the code structure comes from the
stack; the method structure comes from here).

**Existing project:** copy `.claude/`, `AUTONOMY.md`, `docs/mentor/`, `docs/templates/`, `MEMORY.md`
and `memory/`. Merge this kit's `CLAUDE.md` with what already exists — keeping the result short
(see `docs/mentor/01-claude-md-anatomy.md`).

**First session (ritual):**
1. `/guardrails` — a 5-minute interview; generates tailored limits.
2. `/goal <what you want>` — the contract `docs/goals/ACTIVE.md` is born.
3. Work normally.
4. `/retro` when wrapping up — the lessons become written rules.

## The learning flywheel

```
          work
       ↗         ↘
 better            user
 rules             corrections
       ↖         ↙
      /retro records
```

Each turn of the cycle makes the next session better than the last. A model that runs this cycle for
20 sessions accumulates what no initial prompt could contain. **The kit doesn't make the model
smarter; it points the model's intelligence at the right place — and compounds it over time.**

## The `compounder/` plugin — the compound engineering pipeline

Beyond the kit (base method), this repository carries the **compounder** plugin — spiritual successor
to Every's compound-engineering-plugin, redesigned from scratch by Claude Fable 5 for modern
Claude Code and for Opus/Sonnet/Haiku:
`/brainstorm → /plan → /work → /simplify → /review → /compound`, with `/lfg` (autopilot),
`/slfg` (swarm) and `/btw` (asides without derailing). Site: https://lexcesar.github.io/compounder/ — direct install:

```
/plugin marketplace add lexcesar/compounder
/plugin install compounder
```

Comparison with the original and details: `compounder/README.md`.

Division of roles: the **kit** teaches HOW TO THINK (principles, autonomy, memory); the **plugin**
provides the EXECUTION RAIL (pipeline with gates). They reference each other, but each works on its own.

## Maintenance principle

Every file in this kit is a living organism: if a rule never changes a behavior, it dies
(delete it); if a mistake repeats, a rule is born (write it down). `/retro` is the heart that pumps this.
